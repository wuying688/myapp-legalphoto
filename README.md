# Photo Grid Privacy Policy and Support

This repository publishes the Photo Grid iPhone and iPad app privacy policy and support page.

- Privacy policy: https://wyyy688.github.io/myapp-legalphoto/
- Support: https://wyyy688.github.io/myapp-legalphoto/support.html

## Publish

The repository includes a GitHub Actions workflow that publishes these pages when changes are pushed to `main`. GitHub Pages is configured to use **GitHub Actions**, so subsequent updates deploy automatically.
