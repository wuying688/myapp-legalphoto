# Photo Grid Legal

Public legal pages for the Photo Grid iPhone and iPad app.

- Privacy policy: https://wuying688.github.io/myapp-legalphoto/privacy.html
- Landing page: https://wuying688.github.io/myapp-legalphoto/

## Publish

The repository includes a GitHub Actions workflow that publishes the static pages on pushes to `main`. To enable the first deployment, open **Settings → Pages** and set **Source** to **GitHub Actions**. After that, each update to `main` deploys automatically.
